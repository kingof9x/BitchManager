# BitchManager — Block System Hardware // LED & Action Engine

**BitchManager** is the official macOS hardware companion, lighting studio, and MIDI/OSC/Macro router for the **BitchBoy V1** 69-control hardware console.

## 💿 Quick Install (macOS Drag-to-Applications)
1. Download **[BitchManager-Installer.dmg](BitchManager-Installer.dmg)** directly from this repository.
2. Double-click **`BitchManager-Installer.dmg`** to mount the disk image.
3. Drag **`BitchManager.app`** into the **`Applications`** folder shortcut and launch it!

---

## ✨ Key Features
- **Full 69-Control Hardware Console**:
  - **49 RGB/Multi-Velocity LED Keys**: 8×4 Top Grid (32 keys), 1×8 Middle Strip (8 keys), and 3×3 Right Keypad (9 keys).
  - **20 Continuous Controllers**: 8 Vertical Faders, 4 Horizontal Crossfaders, and 8 Rotary Encoders.
- **Reactive Mechanical Keyboard Key-Press FX Engine**:
  - Live interactive 2D spatial effects triggered by physical BitchBoy key presses or on-screen clicks: **Ripple Ring**, **Laser Cross**, **Supernova**, **Heat Trail**, **Meteor Drop**, and **Arc Lightning** with adjustable wave speed, Prism Rainbow mode, and neon color swatches.
- **Custom Lighting FX Studio**:
  - Multi-frame keyframe sequencer, direct 49-key chassis painter, and procedural Wave Synthesizer with 15+ built-in hardware light shows.
- **8-Slot Customizable Memory Bank (`SLOT A` – `SLOT H`)**:
  - Instant bank switching (`BANK A–D` / `BANK E–H`), custom slot icons, color badges, 1-click Save, Clone, and JSON Clipboard Export/Import.
- **MIDI Output Router & Patchbay**:
  - Built-in virtual MIDI source (`BitchBoy Virtual Out`), multi-DAW routing, channel remapping, semitone transpose, and velocity curves.
- **Macro Action Engine**:
  - Trigger multi-step QWERTY keystroke sequences, OSC packets, or AppleScript automations from any hardware key.
